# Acceso Material

Prototipo de una interfaz móvil de inicio de sesión hecho con Kotlin, Jetpack Compose y Material 3. El proyecto se puede abrir en Android Studio desde esta carpeta.

## Ejecutar

1. Abre Android Studio y selecciona **Open** sobre la carpeta del proyecto.
2. Espera la sincronización de Gradle y selecciona un emulador o dispositivo Android.
3. Ejecuta la configuración `app`.

El prototipo incluye acceso, recuperación de contraseña y registro con validación local. No incluye una API ni autenticación real; los mensajes identifican los puntos donde se conectaría el servicio.
